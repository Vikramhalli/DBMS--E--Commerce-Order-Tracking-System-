# 📦 E-Commerce Order Tracking System

A complete backend database solution for managing and automating the order lifecycle of an e-commerce platform.
This project includes **table creation scripts, triggers, stored procedures, and functions** that ensure data accuracy, inventory automation, order consistency, and actionable business insights.

## 🚀 Overview
The E-Commerce Order Tracking System manages:
- Products
- Customers
- Orders & Order Details
- Shipments
- Returns
- Reviews

Automation includes:
- SQL Triggers
- Stored Procedures
- Analytical Functions

## 🔧 Key Features

### 🛒 Inventory & Order Management
- Auto-update stock
- Prevent negative stock
- Auto-calculate order totals

### 🚚 Shipment Tracking
- Tracking numbers, couriers, delivery dates
- Linked shipments

### ↩️ Return Processing
- Manage & approve returns
- Restore inventory

### 📊 Analytics
- Customer order history
- Sales reports
- Product revenue, LTV, ratings
